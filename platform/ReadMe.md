# Ermentrud
A graphic adventure.
More information about this game can be found on the official [homepage](https://www.inutilis.com/portfolio/ermentrud-das-spiel).

# Key bindings
- Space: Pause the game
- Point: Skip sentence

# History
- Version 1.0: first public release (german only)
- Version 1.1: add support for new languages (english, italiano)
